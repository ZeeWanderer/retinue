## Evidence

State the game/provider build, capture date, method and implemented adapter.
Separate verified observations, inference and open questions. Preserve hashes or
bounded extracts needed to reproduce a conclusion. Explain how to rerun the
check with the maintained inspector/toolchain.

Publish only reviewed extracts. Player data is not automatically secret, but
captures may contain session tokens, credentials, cookies, authentication headers
or signed URLs. Full memory dumps are not documentation assets. A keyword scan
alone does not establish that a dump is safe. Keep unreviewed acquisitions out of
the site; link a reviewed artifact only when it is actually available.
